# Airbnb NYC 2019 — Data Analysis

**Portfolio project by Mahak Kumari**

## Overview
This project explores New York City Airbnb listing data from 2019 using Python, Pandas, data visualization, and SQL with SQLite. It examines listing distribution, room types, nightly prices, reviews, host activity, and availability across neighbourhood groups.

## Objectives
- Inspect dataset structure, data types, and missing values.
- Clean and validate listing data before analysis.
- Compare listing counts and nightly prices across boroughs.
- Explore room-type distribution, neighbourhood activity, reviews, and availability.
- Use SQL queries in SQLite to answer business-style questions.
- Export summary tables for further analysis or dashboarding.

## Tools
Python, Pandas, NumPy, Matplotlib, Seaborn, SQLite, Google Colab/Jupyter.

## Dataset
The notebook expects `AB_NYC_2019.csv` or a ZIP containing that CSV.

Source: [New York City Airbnb Open Data — Kaggle](https://www.kaggle.com/datasets/dgomonov/new-york-city-airbnb-open-data)

The dataset includes neighbourhood group, neighbourhood, room type, price, minimum nights, review counts, host listing counts, and annual availability. Follow the dataset provider's terms when using or redistributing it.

## Key findings
The provided dataset contains **48,884 cleaned listings** after removing duplicate records and rows with unusable or invalid key values.

- **Manhattan** has the highest average and median listed nightly price among boroughs in this cleaned dataset.
- **Brooklyn** and **Manhattan** account for most listings.
- **Entire home/apt** is the most common room type, followed by private rooms.
- **Williamsburg** and **Bedford-Stuyvesant** have the highest listing counts among neighbourhoods in this dataset.

These are descriptive findings from listing data, not confirmed booking, occupancy, or revenue results. Listed prices do not necessarily equal prices paid by guests.
